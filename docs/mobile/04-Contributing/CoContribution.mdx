# Co-contribute to Hero Design

This page provides instruction on co-contributing to Hero Design. For in-depth details of Co-Contribution Model, please refer to [this doc](https://employmenthero.atlassian.net/wiki/spaces/CI/pages/2301919315/Co-Contribution+Model.).

## Purpose of Co-Contribution

- Provides transparent development roadmap of Hero Design so that feature squads can plan feature development. The latest roadmap can be found [here](https://employmenthero.atlassian.net/wiki/spaces/ANDR/overview#Current-roadmap).
- If the roadmap does not fit feature development schedule, you can:
  - Wait or reschedule your plan.
  - Consult Andromeda team via [#eh-hero-design](https://employmenthero.slack.com/archives/CHWMT4F44) to prioritize the needed component and update the roadmap.
  - Contribute to Hero Design yourself (**co-contribute**).
- If the needed component does not available in both roadmap and component tree, please create an issue in [Hero Design repository](https://github.com/Thinkei/hero-design/issues/new/choose).
  - This will be discussed with UX team to decide whether the component should belong to Hero Design. Otherwise, you might need to create a snowflake.
  - If the component belongs to Hero Design, then the UIKit will be updated with the official design.
  - Finally, the component will be added to the roadmap.
  - After that, you can choose to co-contribute to speed up the release.

## How to co-contribute

If you'd like to co-contribute to Hero Design, here is the process:

- Visit the [roadmap](https://employmenthero.atlassian.net/wiki/spaces/ANDR/overview#Current-roadmap), look at the time frame, and choose a component to contribute.
- Slack Andromeda team in [#eh-hero-design](https://employmenthero.slack.com/archives/CHWMT4F44) to get approval for co-contribution.
- In [Andromeda board](https://employmenthero.atlassian.net/jira/software/c/projects/ANG/boards/99), the relevant card should have **[Co-Contribution]** prefix in the name.
- In contributor's board, create a card and link to the corresponding card in Andromeda board.
- Contributor works on the component. Instruction on development can be found [here](/mobile/Contributing/development).
- Andromeda team review and release. Contributors and stakeholders should subscribe to [#hero-design-release](https://employmenthero.slack.com/archives/C036V04PQDB) to be notified when the component is released.
