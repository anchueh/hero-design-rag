## Examples

### Basic Radio.Group

```jsx live
function RadioExample() {
  const [value, setValue] = useState('everything');

  return (
    <Radio.Group
      options={[
        { text: 'Everything', value: 'everything' },
        { text: 'Direct mentions only', value: 'direct_mentions' },
        { text: 'Nothing', value: 'nothing' },
      ]}
      value={value}
      onPress={setValue}
    />
  );
}
```

### Intents

Radio.Group supports 2 intents for inactive Radio button: `light` and `dark` that can be used with the `inactiveIntent` prop.

```jsx live
function RadioExample() {
  const [value, setValue] = useState('everything');

  return (
    <Radio.Group
      inactiveIntent="dark"
      options={[
        { text: 'Everything', value: 'everything' },
        { text: 'Direct mentions only', value: 'direct_mentions' },
        { text: 'Nothing', value: 'nothing' },
      ]}
      value={value}
      onPress={setValue}
    />
  );
}
```

### With subtext

Radio.Group also supports rendering subtext using `subText` in the option object.

```jsx live
function RadioExample() {
  const [value, setValue] = useState('on_demand');

  return (
    <Radio.Group
      inactiveIntent="dark"
      options={[
        {
          text: 'On demand/now',
          subText: 'InstaPay Now',
          value: 'on_demand',
        },
        {
          text: 'Everyday',
          subText: 'InstaPay Daily',
          value: 'everyday',
        },
      ]}
      value={value}
      onPress={setValue}
    />
  );
}
```
