## How many types?

There are 2 types of FAB button sizes:

### Default

```jsx live previewOnly
<Box padding="medium">
  <FAB icon="chat-bubble-outlined" />
</Box>
```

<br />

### Extended

```jsx live previewOnly
<Box padding="medium">
  <FAB icon="pencil" title="Shout out" />
</Box>
```
