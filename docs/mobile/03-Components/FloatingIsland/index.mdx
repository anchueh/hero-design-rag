# Floating Island

Floating Island is a wrapper that is placed at the top of the screen and can be used to trigger various actions with the `onPress` prop.

## Example

### Basic

Here is an example of a Floating Island that opens a `BottomSheet` when pressed.

If no `onPress` prop is provided, the Floating Island will be treated as a normal container component.

```jsx live noInline
function FloatingIslandPlayground() {
  const [bottomSheetVisible, setBottomSheetVisible] = React.useState(false);

  return (
    <Box
      style={{
        width: '100%',
        height: 75,
        alignItems: 'center',
        justifyContent: 'center',
      }}
    >
      <FloatingIsland onPress={() => setBottomSheetVisible(true)}>
        <Box
          style={{
            flexDirection: 'row',
            justifyContent: 'center',
            alignItems: 'center',
          }}
        >
          <Tag content="IN PROGRESS" />
          <Icon
            icon={bottomSheetVisible ? 'caret-up' : 'caret-down'}
            style={{
              fontSize: theme.fontSizes.xsmall,
              marginLeft: theme.space.small,
            }}
          />
        </Box>
      </FloatingIsland>

      <BottomSheet
        open={bottomSheetVisible}
        header="Title"
        onRequestClose={() => setBottomSheetVisible(false)}
        variant="floating"
      >
        <Typography.Body style={{ padding: theme.space.medium }}>
          Bottom sheet content
        </Typography.Body>
      </BottomSheet>
    </Box>
  );
}

render(FloatingIslandPlayground);
```

### Prefix and Suffix

`FloatingIsland` also supports `prefix` and `suffix` props to add content before and after the children.

```jsx live
function FloatingIslandPlayground() {
  return (
    <Box
      style={{
        width: '100%',
        height: 100,
        alignItems: 'center',
        justifyContent: 'center',
      }}
    >
      <FloatingIsland
        onPress={() => alert('Pressed')}
        prefix="calendar"
        suffix={<Tag intent="warning" content="PENDING" />}
      >
        <Box
          style={{
            justifyContent: 'center',
          }}
        >
          <Typography.Body variant="small-bold">
            Nov 21, 1:00 - 4:00 PM
          </Typography.Body>

          <Typography.Body variant="small" intent="subdued">
            Meeting pending
          </Typography.Body>
        </Box>
      </FloatingIsland>
    </Box>
  );
}
```
