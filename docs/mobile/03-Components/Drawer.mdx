# Drawer

A drawer is a temporary workspace that allows users to complete tasks without navigating to a new page.

## Example

### Example 1: Drawer with backdrop

```jsx live noInline
const { Body } = Typography;

const Content = () => (
  <View style={{ padding: 30 }}>
    <Body>Drawer Content</Body>
    <Body>Drawer Content</Body>
    <Body>Drawer Content</Body>
    <Body>Drawer Content</Body>
    <Body>Drawer Content</Body>
    <Body>Drawer Content</Body>
    <Body>Drawer Content</Body>
  </View>
);

const App = () => {
  const [visible, setVisiblity] = useState(false);

  return (
    <Box justifyContent="center" style={{ height: 300 }}>
      <Button
        text="Toggle Drawer"
        variant="text"
        onPress={() => setVisiblity(!visible)}
      />
      <Drawer visible={visible} onDismiss={() => setVisiblity(false)}>
        <Content />
        <Button
          text="Close drawer"
          variant="text"
          onPress={() => setVisiblity(false)}
        />
      </Drawer>
    </Box>
  );
};

render(<App />);
```

### Example 2: Drawer without backdrop

```jsx live noInline
const { Body } = Typography;

const Content = () => (
  <View style={{ padding: 30 }}>
    <Body>Drawer Content</Body>
    <Body>Drawer Content</Body>

    <Body>Drawer Content</Body>
    <Body>Drawer Content</Body>
    <Body>Drawer Content</Body>
    <Body>Drawer Content</Body>
  </View>
);

const App = () => {
  const [visible, setVisiblity] = useState(false);

  return (
    <Box justifyContent="center" style={{ height: 300 }}>
      <Button
        text="Toggle Drawer"
        variant="text"
        onPress={() => setVisiblity(!visible)}
      />
      <Drawer
        hasBackdrop="false"
        visible={visible}
        onDismiss={() => setVisiblity(false)}
      >
        <Content />
        <Button
          text="Close drawer"
          variant="text"
          onPress={() => setVisiblity(false)}
        />
      </Drawer>
    </Box>
  );
};

render(<App />);
```
