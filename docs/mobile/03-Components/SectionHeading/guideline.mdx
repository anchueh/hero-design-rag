## Where should I use this?

Section headings are rarely used alone and are typically used to label a group of dashboard widgets, lists, menu lists, text inputs, cards and data cards.

<br />

#### With icon

Used to label a group of menu list.

```jsx live previewOnly
<>
  <SectionHeading
    text="Mandatory"
    icon="assignment-warning"
    style={{ marginBottom: 0 }}
  />
  <Box padding="medium" style={{ height: 100 }}>
    <Typography.Title level="h5">App test </Typography.Title>
    <Typography.Caption>Updated on Nov 23, 2023</Typography.Caption>
  </Box>
  <SectionHeading text="Nonmandatory" icon="list" style={{ marginBottom: 0 }} />
  <Box padding="medium" />
</>
```

<br />

<br />

#### Default

Used to label a group of text inputs.

```jsx live previewOnly
<>
  <SectionHeading text="Address" style={{ marginBottom: 0 }} />
  <Box padding="medium">
    <TextInput label="Line 1" />
    <TextInput label="Line 2" />
    <TextInput label="City" />
  </Box>
</>
```

<br />

#### With badge

Used to label a group of cards.

```jsx live previewOnly
<>
  <SectionHeading
    text="Bidding Employees"
    style={{ marginBottom: 0 }}
    rightChildren={<Badge content={5} intent="primary" />}
  />
  <Box padding="medium" style={{ height: 100 }}>
    <Typography.Title level="h5">Employee 1</Typography.Title>
  </Box>
  <Divider />
  <Box padding="medium" style={{ height: 100 }}>
    <Typography.Title level="h5">Employee 2</Typography.Title>
  </Box>
  <Divider />
  <Box padding="medium" style={{ height: 100 }}>
    <Typography.Title level="h5">Employee 3</Typography.Title>
  </Box>
  <Divider />
  <Box padding="medium" style={{ height: 100 }}>
```
