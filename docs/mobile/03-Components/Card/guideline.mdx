## Tips for...

### Content

<Ul>
  <Li>
    The label used to categorise a set of cards should always be concise and
    descriptive, using no more than 2-3 words, such as “Activity”, “Team goals”
    etc.
  </Li>
  <Li>
    A card can contain icons, tags, avatars, logos, badges, dividers, data
    visualisations, or plain text. Consider if there are any actions the user
    should take after reviewing the contents of the card, or if there is an
    option to view the information in more detail on a separate screen.
  </Li>
  <Li>
    When laying out the content of a card, keep our baseline grid in mind
    whenever possible.
  </Li>
  <Li>
    Consider the visual hierarchy of the card content design, always prioritise
    repurposing an existing card design rather than creating a new one.
  </Li>
</Ul>

### Calls to actions

- A CTA on cards is optional, use an icon button if required, and it should be presented on the ending side of a card.
