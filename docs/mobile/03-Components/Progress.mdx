# Progress

Progress is used to display:

- The current progress of a long operation.
- The completion in percentage of an operation.

## Example

### Basic Progress Bar

Render a progress bar by specifying `value` prop. Valid value is in range of `[0,100]`

```jsx live
function BasicProgressExample() {
  const [progress, setProgress] = useState(0);

  return (
    <Box marginTop="large">
      <Progress.Bar
        value={progress}
        style={{ marginBottom: theme.space.medium }}
      />
      <Button
        variant="text"
        text="Random Value"
        onPress={() => setProgress(Math.floor(Math.random() * 100))}
      />
    </Box>
  );
}
```

### Basic Progress Circle

Render a progress circle by specifying `value` prop. Valid value is in range of `[0,100]`

```jsx live
function BasicProgressCircleExample() {
  const [progress, setProgress] = useState(0);

    <Box

```

### Intents

Progress Bar and Progress Circle come with 10 intents which are:

- `primary`, `success`, `warning`, `danger`, `info`, `archived`.
- `primary-inverted`, `success-inverted`, `warning-inverted`, `danger-inverted`, `info-inverted`, `archived-inverted`.

        </Box>
      </Box>
    </>
  );
}

### Progress.Step

```jsx live
function ProgressStep() {
  return (
    <Box padding="medium">
      <Typography.Body style={{ marginBottom: theme.space.medium }}>
        Single step
      </Typography.Body>
      <Progress.Step steps={1} current={0} />
      <Typography.Body style={{ marginVertical: theme.space.medium }}>
        Completed single step
      </Typography.Body>
      <Progress.Step steps={1} current={1} />

      <Typography.Body style={{ marginVertical: theme.space.medium }}>
        Multiple steps
      </Typography.Body>
      <Progress.Step steps={5} current={3} />
    </Box>
  );
}
```
