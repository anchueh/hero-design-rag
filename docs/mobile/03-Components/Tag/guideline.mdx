## Tips for writing Tags’ label

- Use a single world to describe the status of an object
- Only use two words if you need to describe a complex status or a quantifiable status, such as ‘Sync Pending’ or ‘2 Outstanding’
- Always describe the status in the past tense, such as ‘Archived’ not ‘Archive’

### The available tags for timesheet status are:

- Draft
- Submitted
- Approved
- Processed
- Rejected

### The available tags for roster status are:

- Pending shift
- Bidding shift
- Proposed shift swap
- Assigned shift

### The available tags for dashboard widgets are:

- 1 Pending
- 1 Outstanding
