# Bottom Sheet

Bottom sheets are surfaces containing supplementary content that are anchored to the bottom of the screen.

## Example

:::info Landscape mode
To use this component in landscape mode on iOS, you must first pass the `supportedOrientations` prop as specified in the [React Native doc](https://reactnative.dev/docs/modal#supportedorientations-ios).
:::

<br />

### Example 1: Basic usage

Basic Bottom Sheet with backdrop.

```jsx live
function Example1() {
  const [open, setOpen] = useState(false);

  return (
    <>
      <Button
        variant="text"
        text="Toggle Bottom Sheet"
        onPress={() => setOpen(true)}
      />
      <BottomSheet open={open} onRequestClose={() => setOpen(false)}>
        <>
          <Typography.Body variant="small">
            Bottom Sheet Content
          </Typography.Body>
          <Typography.Body variant="small">
            Bottom Sheet Content
          </Typography.Body>
          <Typography.Body variant="small">

            Bottom Sheet Content

          <Typography.Body variant="small">
            Bottom Sheet Content
```

### Example 3: Bottom Sheet with Header & Footer

Bottom Sheet can be config to have a header and a footer

```jsx live
function Example3() {
  const [open, setOpen] = useState(false);

  return (
    <>
      <Button
        variant="text"
        text="Toggle Bottom Sheet"
        onPress={() => setOpen(true)}
      />
      <BottomSheet
        open={open}
        onRequestClose={() => setOpen(false)}
        header="Title"
        footer={
          <View style={{ flexDirection: 'row', alignItems: 'flex-end' }}>
            <Button
              variant="text"
              text="Close"
              onPress={() => setOpen(false)}
            />
          </View>
        }
      >
        <View style={{ padding: theme.space.medium }}>
          <Typography.Body variant="small">
```
