# Typography

- Typography is for text writing including title, subtitle, text and paragraph.
- This component makes it easy to apply a default set of font weights, sizes and colors in your application.

## Examples

### Typography.Title

There are 2 typefaces: `neutral` and `playful`:

- `neutral` supports 6 levels of a Title: `h1`, `h2`, `h3`, `h4`, `h5`, `h6`
- `playful` supports 5 levels of a Title: `h1`, `h2`, `h3`, `h4`, `h5`

#### Neutral typeface

### Typography.Body

There are 2 typefaces: `neutral` and `playful`:

- `neutral`: Body, Body Bold, Body small and Body small bold
- `playful` Body and Body Bold

#### Neutral typeface

```jsx live
function TypographyBodyNeutral() {
  return (
    <Box padding="medium" style={{ paddingTop: 0 }}>
      <Box>
        <Typography.Body>Body</Typography.Body>
        <Typography.Body>
          This style is the standard for body copy. It should be used for long
          paragraphs with four lines or more. It is always left-aligned.
        </Typography.Body>
      </Box>
      <Divider
        style={{
          marginTop: theme.space.medium,
          marginBottom: theme.space.medium,
        }}
      />
      <Box>
        <Typography.Body
          style={{ marginBottom: theme.space.small }}
          variant="regular-bold"
        >
          Body Bold
        </Typography.Body>
        <Typography.Body variant="regular-bold">
          This style is used for expressive body copy. It should only be used to
          compliment body-01, for CTAs or in-line links.
        </Typography.Body>
      </Box>
      <Divider
        style={{
          marginTop: theme.space.medium,
          marginBottom: theme.space.medium,
        }}
      />
      <Box>
        <Typography.Body
          style={{ marginBottom: theme.space.small }}
          variant="small"
        >
          Body Small
        </Typography.Body>
        <Typography.Body
          style={{ marginBottom: theme.space.small }}
          variant="small"

        </Typography.Body>

          style={{
            marginTop: theme.space.medium,
            marginBottom: theme.space.medium,

          variant="small-bold"

          Body Small Bold

          style={{ marginBottom: theme.space.small }}

          The style is for secondary body copy. It should be used to compliment
```

```jsx live
  );
}
```

### Typography.Caption

This is a multipurpose type style that can be used for tertiary information. It can also be used for explanatory helper text that appears below a input field within a component. It should not be used for body copy.

```jsx live

  return (
    <Box padding="medium">
      <Typography.Caption>This is regular caption</Typography.Caption>
      <Typography.Caption fontWeight="semi-bold">
        This is bold caption
      </Typography.Caption>
      <Typography.Caption intent="subdued" fontWeight="light">
        This is subdued caption
      </Typography.Caption>
      <Typography.Caption intent="primary" fontWeight="light">
        This is primary caption
      </Typography.Caption>
      <Typography.Caption intent="success" fontWeight="light">
        This is success caption
      </Typography.Caption>
      <Typography.Caption intent="info" fontWeight="light">
        This is info caption
      </Typography.Caption>
      <Typography.Caption intent="warning" fontWeight="light">
        This is warning caption
      </Typography.Caption>
      <Typography.Caption intent="danger" fontWeight="light">
        This is danger caption
      </Typography.Caption>
      <Typography.Caption intent="archived" fontWeight="light">
```

### Intents

All Typography components come with the following intents: `body`, `subdued`, `primary`, `secondary`, `success`, `info`, `warning`, `danger`, `inverted`, `archived`, `disabled` and `muted`.

```jsx live
function IntentExamples() {
  const textIntents = [
    'body',
    'subdued',
    'primary',
    'secondary',
    'success',
    'info',
    'warning',
    'danger',
    'inverted',
    'archived',
    'disabled',
    'muted',
    ] as const;

  return (
    <Box padding="medium">
      {textIntents.map((intent) => (
      <Box
        style={{
          backgroundColor:
            intent === 'inverted' ? theme.colors.darkGlobalSurface : undefined,
        }}
      >
        <Typography.Body
          intent={intent}
          style={{
            marginBottom: theme.space.small,
          }}
        >
          This is {intent} intent
        </Typography.Body>
      </Box>
    ))}
    </Box>
)};
```
