## Writing alerts content

Alerts should be written in a concise manner. It is recommended that alert descriptions do not exceed 2-3 lines of text. Headings, flat buttons or inline text links may be included to support the alert’s message.

<br />

```jsx live previewOnly
<Box
  padding="large"
  flexDirection="row"
  alignItems="center"
  justifyContent="center"
  style={{ flexWrap: 'wrap', gap: theme.space.medium }}
>
  <Alert
    title="Info"
    content="There will be a scheduled maintenance from 7 A.M to 8 A.M."
    intent="info"
    style={{
      width: '48%',
    }}
    onClose={() => alert('Closed')}
  />

  <Alert
    title="Error"
    content="Last name is not valid. Please remove any symbols or numbers."
    intent="error"
    style={{
      width: '48%',
    }}
    onClose={() => alert('Closed')}
  />

  <Alert
    title="Success"
    content="This policy has been successfully acknowledged."
    intent="success"
    style={{
      width: '48%',
    }}
    onClose={() => alert('Closed')}
  />

  <Alert
    title="Warning"
    content="Please proceed to enrol a card before you start shopping."
    intent="warning"
    style={{
      width: '48%',
    }}
    onClose={() => alert('Closed')}
  />
</Box>
```

<br />

Avoid using technical jargon or overly complex language - alerts should be easy to understand for all users.

<br />

## Use icons in alerts

Icons should provide an additional information about the alert to assist the
user in quickly and easily identifying the message. The user should always be
able to close the alert therefore a dismiss icon should always be visible unless
an actionable button that behaves similarly is present.

```jsx live previewOnly
<Box padding="large" flexDirection="row" style={{ gap: theme.space.large }}>
  <Icon icon="circle-ok" />
  <Icon icon="circle-info" />
  <Icon icon="circle-question" />
  <Icon icon="warning" />
</Box>
```

<br />
<br />

## Behavior

Limit the frequency of alerts - excessive alerts can be distracting and annoying to users.
