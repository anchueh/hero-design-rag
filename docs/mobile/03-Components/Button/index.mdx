## Examples

#### Intents & Variants

Button comes with

- 3 intents which are `primary`, `secondary`, and `danger`.
- 4 variants which are `filled`, `outlined`, `text` and `inline-text`.
- 2 compact variants which are `filled-compact` and `outlined-compact`.

#### Filled variant

```jsx live
function App() {
  return (
    <>
      <Typography.Body
        variant="small"
        style={{ marginBottom: theme.space.xsmall }}
      >
        Variants
      </Typography.Body>
      <Button
        text="Primary (Filled)"
        variant="filled"
        intent="primary"
        onPress={() => {}}
        style={{ marginBottom: theme.space.medium }}
      />
      <Button
        text="Filled (Loading)"
        variant="filled"
        intent="primary"
        onPress={() => {}}
        style={{ marginBottom: theme.space.medium }}
        loading
      />
    </>
  );
}
```

```jsx live
  return (
    <>

        variant="small"
```

```jsx live
        <Button
          text="Primary (Text)"
          variant="text"
          intent="primary"
          onPress={() => {}}
          style={{ marginBottom: theme.space.medium }}
        />
        <Button
          text="Secondary (Text)"
          variant="text"
          intent="secondary"
          onPress={() => {}}
          style={{ marginBottom: theme.space.medium }}
        />
        <Button
          text="Danger (Text)"
          variant="text"
          intent="danger"
          onPress={() => {}}
          style={{ marginBottom: theme.space.medium }}

      <View style={{ alignItems: 'center' }}>
```


#### Button with icon

Button icons can either be an icon name or a custom component.

```jsx live
function App() {
  return (
    <>
      <Typography.Body
        variant="small"
        style={{ marginBottom: theme.space.xsmall }}
      >
        With Icon
      </Typography.Body>
      <Button
        text="Add Item"
        variant="filled"
        intent="primary"
        icon="add"
        onPress={() => {}}
        style={{ marginBottom: theme.space.medium }}
      />
      <Button
        text="More"
        variant="outlined"
        intent="primary"
        rightIcon="arrow-down"
        onPress={() => {}}
        style={{ marginBottom: theme.space.medium }}
      />
      <Button
        text="Submit"
        variant="text"
        intent="primary"
        icon={<Icon icon="send" size="small" />}
        onPress={() => {}}
        style={{ marginBottom: theme.space.medium }}
      />
    </>
  );
}
```

```jsx live
        onPress={() => {}}
        style={{
          marginBottom: theme.space.medium,
          marginRight: theme.space.medium,

      />
    </Box>
  );
}
```
