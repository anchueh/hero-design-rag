## Default

The DatePicker consists of date, month and year, and same as the time picker, it allows users to control value selection by scrolling up or down on the corresponding wheel.

## Calendar

The day of the week (DOW) picker allows users to select a day of the week from a calendar view. DOW pickers typically displays the days of the week as abbreviated text labels above, and offer navigation options for moving between different time period. Use this variant sparingly, as it currently doesn’t support quick navigation between months and years.

### Basic

```jsx live
function DatePickerPlayground() {
  const theme = useTheme();
  const [value, setValue] = useState(new Date('1995-06-17T00:00:00.000Z'));

  const minDate = new Date('1995-01-01T00:00:00.000Z');
  const maxDate = new Date('1995-12-31T00:00:00.000Z');
  return (
    <>
      <Typography.Body variant="small">Date Picker (Calendar)</Typography.Body>
      <DatePicker
        value={value}
        minDate={minDate}
        maxDate={maxDate}
        label="Start"
        confirmLabel="Confirm"
        onChange={(date) => setValue(date)}
        variant="calendar"
      />
    </>
  );
}
```
