# Badge

- Badge is used to describe status or value of a text.
- It can be used as standalone status; or a notification.

## Examples

There are 2 types: **Standalone** and **Status**.

### Standalone

#### Intents

Badge comes with 6 intents which are `primary`, `success`, `warning`, `danger`, `info`, and `archived`.

`${max}+` is displayed when content is number and larger than `max`. Default value of `max` is 99.

```jsx live
        <Button

        />
```

#### Icon

Icon can be used as the content of the badge.

```jsx live
<View
  style={{
    display: 'flex',
    flexDirection: 'row',
    alignItems: 'flex-end',
  }}
>
  <Badge
    icon="checkmark"
    size="small"
    intent="primary"
    style={{ marginEnd: theme.space.small }}
  />

  <Badge icon="cancel" size="small" style={{ marginEnd: theme.space.small }} />

  <Badge
    icon="add"
    size="small"
    intent="success"
    style={{ marginEnd: theme.space.small }}
  />

  <Badge
    icon="checkmark"
    intent="primary"
    style={{ marginEnd: theme.space.small }}
  />

  <Badge icon="cancel" style={{ marginEnd: theme.space.small }} />

  <Badge icon="add" intent="success" style={{ marginEnd: theme.space.small }} />

```

### Sizes

Badge comes with 2 sizes which are `small` and `medium`. The default size is `medium`.

```jsx live
<View style={{ display: 'flex', flexDirection: 'row', alignItems: 'flex-end' }}>
  <Badge
    size="small"
    content="SMALL"
    intent="primary"
    style={{ marginEnd: theme.space.small }}
  />
  <Badge size="medium" content="MEDIUM" intent="primary" />
</View>
```

### Status

Status Badge comes with 6 intents which are `primary`, `success`, `warning`, `danger`, `info`, and `archived`.

```jsx live
function App() {
  const [isVisibleBadge, setIsVisibleBadge] = React.useState(true);
  const [isVisibleStatusBadge, setIsVisibleStatusBadge] = React.useState(true);

  return (
    <>
      <View
        style={{
          display: 'flex',
          flexDirection: 'row',
          marginBottom: theme.space.small,
        }}
      >
        <Badge.Status style={{ marginEnd: theme.space.small }}>
          <Icon icon="bell" size="small" />
        </Badge.Status>
        <Badge.Status intent="primary" style={{ marginEnd: theme.space.small }}>
          <Icon icon="bell" size="small" />
        </Badge.Status>
        <Badge.Status intent="warning" style={{ marginEnd: theme.space.small }}>
          <Icon icon="bell" size="small" />
        </Badge.Status>
        <Badge.Status intent="info" style={{ marginEnd: theme.space.small }}>
          <Icon icon="bell" size="small" />
        </Badge.Status>
        <Badge.Status intent="success" style={{ marginEnd: theme.space.small }}>
          <Icon icon="bell" size="small" />
        </Badge.Status>
        <Badge.Status
          intent="archived"
          style={{ marginEnd: theme.space.small }}
        >
          <Icon icon="bell" size="small" />
        </Badge.Status>
        <Badge.Status intent="primary" style={{ marginEnd: theme.space.small }}>
```
