# Layout

Layout is the framework for the structure and composition of a screen. It refers to how the components of a screen are organised in relation to the screen size and each other. Applying a layout ensures consistency, familiarity and visual harmony for the user which enhances their experience and aids their ability to process information on a screen.
The layout is made up of columns, gutters and margins.

## Layout

For Hero Design mobile, all screens must be designed on an iPhone 14 (390px by 844px - height may be relative to content), this means the layout is applied to these measurements as a baseline when designing and building your app. As user devices range is screen size, we must ensure the layout is responsive. This means, for the end user, the layout will scale larger or smaller than an iPhone 14 depending on the device as to achieve optimal visual legibility and a good user experience.

## Columns

A guiding system of spacial areas on the screen that helps us place content. For Hero Design mobile, we always use a responsive 4-column grid layout as the base of our screens. This ensures consistency across all our screens and user devices. On an iPhone 14, the columns will be 78px width. The columns are responsive to multiple devices, this means it will expand or shrink in width depending on the user’s device.

## Gutters

A gutter is the space between each column. For the Hero Design mobile grid, we use 4 columns so 3 gutters will be present. The gutter must be 16px in width. The gutters are responsive to multiple devices, this means it will expand or shrink in width depending on the user’s device.

## Margins

A margin is the space between the left and right edges of the screen and the content. Margins help provide alignment and space for the content. Margins For Hero Design mobile, the Margins are fix a width at 16px each side.
